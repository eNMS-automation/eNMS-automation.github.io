Platform Overview

Everything you need to automate your network—a single platform for inventory, visualization, and automation.

Workflow Engine

Build complex automation workflows visually or let AI generate them for you. Chain services together with conditional logic.

Configuration Management

Automatically pull, store, and diff device configurations. Search across all configs with regex support.

Network Visualization

Display your network on an interactive world map or logical site views. Real-time device status at a glance.

Secure by Design

All credentials stored in HashiCorp Vault. Role-based access control and full audit logging.

Highly Extensible

Any Python script becomes a service in eNMS. Integrates with Ansible, Netmiko, NAPALM, and your custom tools.

Scheduling

Schedule any task to run later, once or on a recurring basis. Full calendar view with execution history.

Design automation workflows visually or let AI build them for you. Chain services with conditional branching, loops, and parallel execution to automate any network operation.

Monitor workflow execution in real time with a hierarchical tree view. Instantly see which services passed, failed, or are still running across all your devices.

Visualize your entire network on an interactive world map. See device status at a glance, filter by pool, and launch automation directly from the map.

Build logical network topology diagrams with nested sub-networks. Organize devices and links visually, then run services against any group with a single click.

Search across thousands of device configurations instantly with full regex support. Find exactly where a routing policy, ACL, or any config pattern is deployed.

Compare device configurations side by side across any two points in time. Spot unauthorized changes, verify compliance, and track every modification automatically.
